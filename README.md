# AI Website Copy Generator for Local Businesses

## Project Overview

This project demonstrates how Prompt Engineering and Generative AI can help local businesses generate professional, conversion-focused website copy.

The system was designed for a local salon business but can also be adapted for:

* Cafes
* Clinics
* Coaching Institutes
* Agencies
* Freelancers

---

# Business Chosen

## GlowNest Salon & Spa

Bangalore, India

---

# Problem Solved

Many local businesses struggle with:

* unclear website messaging
* weak calls-to-action
* generic website content
* poor customer engagement

This project uses AI-generated prompts to create:

* Homepage copy
* Services page content
* CTA sections
* Tone-adapted website messaging

# Prompt Logic

The prompts are designed to:

1. Understand the business type
2. Identify the target audience
3. Adapt the writing tone
4. Generate customer-focused messaging
5. Create persuasive CTA sections
